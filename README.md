#### 🤖 CapyAgent & ИИ-решения для бизнеса

Разрабатываю платформу агентов, которые интегрируются в инфраструктуру компании (CRM, 1С, телефония, тендеры, почта, Telegram) и выполняют реальную работу вместо людей:

| Направление | Что делает агент |
|---|---|
| **[CapyAgent Core](https://capyagent.ru)** | Автономное ядро выполнения задач, локальный и облачный контур, оркестрация инструментов, BSL 1.1 |
| **Разбор тендеров и документации** | Мониторинг площадок по ОКПД2, семантический фильтр требований, подготовка пакетов документов |
| **Обработка заявок и расчёт КП** | Автоматический подбор номенклатуры по базе компании, расчёт маржи и подготовка черновика КП менеджеру |
| **Аудит звонков и CRM-сторож** | Транскрипция, сверка со сценариями продаж, скоринг лидов и выявление дефектов обслуживания |
| **Ассистенты по 1С и базам знаний** | Быстрые ответы команде и клиентам из корпоративных регламентов и учетных систем |
