### Маркетолог и аналитик, который вайбкодит свои продукты

Сначала - маркетинг и аналитика: гипотезы, цифры, воронки, рост.<br>
Потом - вайбкодинг: довожу идею до продукта в проде сам, без команды разработки.<br>
Сейчас - ИИ-агенты: те же цифры и воронки, только рутину внутри рабочих систем делает агент.

#### 🤖 ИИ-агенты

Собираю агентов, которые живут внутри рабочих систем компании - CRM, реклама, коллтрекинг, тендерные площадки, почта и Telegram - и делают работу, а не отчёты о работе.

| Направление | Что делает агент |
|---|---|
| **Аналитика обращений** | Собирает лиды из CRM, рекламы и коллтрекинга, чистит спам и дубли, считает деньги по каналам |
| **Тендеры** | Мониторит закупки, отсеивает мусор, разбирает подходящее и учится на реакциях |
| **Обработка заявок** | Читает заявку, подбирает позиции по базе, считает и готовит черновик КП менеджеру |
| **Ассистенты в Telegram** | Отвечают, ставят задачи и приносят сводки туда, где команда уже сидит |

[**Каталог агентов с ценами**](https://smolnikov.su/agents) · [**Внедрение**](https://smolnikov.su) · [**Обучение работе с ИИ**](https://academy.smolnikov.pro)

Платформа под агентов своя (InterClaw / CapyAgent), репозитории закрыты.
